### FilecryptionCC
### Journal Through Development
## First Goal
The first goal of making this program was to successfully encrypt a file from
the command line. This could be done with any symmetric encryption type. The
purpose of this is to be able to achieve taking commands from the CL and 
translate them into something meaningful in the main file; filecryption.py. 

Additionally, by starting off with a simple task as this, I can also begin to
slowly learn and implement a simple GUI using PyQt.
